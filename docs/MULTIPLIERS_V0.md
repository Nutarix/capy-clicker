# Multipliers v0 — слои уюта для Семьи

Playable pack: еда, места, роли, декор, исследования.
Терминология: всегда **Семья**, никогда «стадо».

Связанные: [`BALANCE_V0.md`](BALANCE_V0.md), [`PRESTIGE_V0.md`](PRESTIGE_V0.md),
[`ROADMAP.md`](ROADMAP.md), [`PLAYTEST_MULTIPLIERS_V0.md`](PLAYTEST_MULTIPLIERS_V0.md).

## Порядок стакинга (источник правды)

```
base
  → temporary (лужа/трава-ускорение: max; × еда; × места)
  → roles
  → decor
  → research (точечные эффекты; flat auto = 1.0 в v0)
  → Уют prestige
```

Формула авто-прогресса:

`auto = base × temp × (1+Σ няня) × (1+Σ decor.auto) × researchAuto(=1) × (1 + uyut×0.03)`

HUD не раздуваем: всё под sheet **«Уют семьи»** (табы Еда / Роли / Дом / Наука)
+ чип «уют N» и кнопка «Уют · N🍽» в spend-панели.

## Unlock order (мягкий)

Старт: лужа, пень, камень, еда (дроп), 1 слот роли, декор за траву.  
После травы/Уюта: research → тент, 2-й слот, лампа, soft-cap.  
Уют prestige остаётся верхним постоянным слоем.

## Self-check

- Нет soft-lock: отказ трат если не хватает; grass/uyut ≥ 0.
- Места с CD; еда списывается только при успехе.
- Семья на всех полянах сохраняет роли в сейве.
