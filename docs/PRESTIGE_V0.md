# Prestige v0 — бесконечный уютный горизонт

Проблема вертикального слайса и мягкий prestige без hard wipe.
Тон: **уютное обживание**, не завоевание. Терминология: всегда **Семья**, никогда «стадо».

Связанные: [`ROADMAP.md`](ROADMAP.md), [`BALANCE_V0.md`](BALANCE_V0.md),
[`FOREST_MAP_V0.md`](FOREST_MAP_V0.md), [`GAMELOOP_V1.md`](GAMELOOP_V1.md).

---

## Проблема

Finite vertical slice (Тёплая опушка → … → Большой луг → Капи Lv.4) ощущается
как **game over**: HUD «Цели закрыты», некуда идти. Игрок обустроил луг —
и горизонт обрывается. Это ломает cozy-кликер: нужен **бесконечный горизонт**,
а не wipe и не «ты победил, выходи».

**Act 1 не должен заканчиваться на Большом луге / Lv.4.**

---

## Паттерны конкурентов (кратко)

| Игра / жанр | Паттерн | Что берём / не берём |
|-------------|---------|----------------------|
| Cookie Clicker / Egg Inc. | Hard prestige: сброс прогресса → meta-валюта | Meta-валюта **да**; hard wipe **нет** |
| Merge-игры (карта слоёв) | Новые слои карты, старые остаются | **Map layers** — да |
| Soft rank prestige | Лёгкий ранг / глава без обнуления | Soft rocket later — да |

---

## Наша модель

1. **Слои карты (biomes / леса)** — новый биом = мини-prestige: свежая опушка,
   старые поляны и их семьи остаются и всегда посещаемы.
2. **Мягкий rocket prestige (позже)** — глава «ракета + планета»: wow + gallery;
   континенты можно сжать в pins на world-map. Не v0.
3. **Визит старых планет / лугов** — всегда можно вернуться «посмотреть, как живут».

### Meta-валюта «Уют» (Искры уюта)

| Свойство | Правило |
|----------|---------|
| Имя | **Уют** (альт. «Искры уюта») |
| Когда | При завершении главы / биома (v0: первый раз после цепочки Большой луг + Капи Lv.4) |
| Эффект | Постоянный мягкий буст к авто-траве / авто-прогрессу |
| Wipe | **Никогда** не сбрасывается |
| Soft cap | Позже (не в v0) |

### Near-term Act (после Great Glade / семьи Lv.4)

После цели «Большой луг» + «Капи Lv.4» → разблокировка **второго лесного биома**
**«Туманный бор»** как mini-prestige:

- Новая стартовая поляна биома (`mist_edge` / Туманная опушка) с 2× Lv.1
- Поляны первого леса («Солнечные поляны») остаются на карте со своими семьями
- Трава **общая**; **Уют** глобальный; семьи — **per meadow**

### Later: ракета + планета

Prestige-глава с wow и gallery. Континенты → pins. Вне скоупа v0
(нет полноценной анимации ракеты, IAP, реген store PNG).

## Баланс (эскиз)

| Параметр | v0 |
|----------|----|
| Первый Уют | После полного «акта» леса: `sunnyGladeAnnounced ≥ 3` **и** max Lv ≥ 4 |

| Soft cap | Позже (ориентир конкурентов: +2–5% за пункт до мягкого потолка) |

## Цели сессии (бесконечный горизонт)

Ягодная → Солнечный прогал → Большой луг → Капи Lv.4 →
**Открой Туманный бор** → **Загляни в Туманный бор** → **Собери искры уюта**
(мягкая цель, не закрывает игру).

Никогда: «игра окончена» / «Цели закрыты».

## Self-check v0

- После Lv.4 / Большого луга всегда есть следующая цель
- Уют в сейве и на HUD; буст применяется к авто
- Туманный бор: locked → unlocked chip; вход = свежая опушка; старые поляны живы
- Нет soft-lock (всегда можно играть на `warm_edge` / открытых полянах)
