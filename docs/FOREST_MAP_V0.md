# Карта леса — Phase 2 (v0)

Уютное переключение между **именованными полянами** одного леса.
Семьи **персистятся per meadow**; кошелёк травы — **общий**.

Связанные документы: [`ROADMAP.md`](ROADMAP.md), [`WORLD_ZONES.md`](WORLD_ZONES.md),
[`GAMELOOP_V1.md`](GAMELOOP_V1.md).

Исходники: `GameState.meadows` / `activeMeadowId`,
`GameController.switchToMeadow`, виджет `ForestMapOverlay`.

---

## Зачем

Act 1 уже раскрывал «Солнечные поляны» как **ступени размера одного луга**
(Тёплая опушка → Ягодная → Солнечный прогал → Большой луг). Phase 2
превращает те же четыре круга в **посещаемые поляны**: можно уйти на новую
опушку с маленькой семьёй и позже вернуться «посмотреть, как живут» на
старой.

Тон: **уютное обживание**, не завоевание. Карта — мягкий оверлей, не
мета-меню с давлением.

---

## Модель

| Что | Где живёт |
|-----|-----------|
| Семья, прогресс-бар спавна, twin-sparkle | **per meadow** (`meadows[id]`) |
| Трава (grass), цели сессии, daily, `nextId` | **глобально** |
| Разблокировка | `sunnyGladeAnnounced` (макс. индекс) |
| Активная поляна | `activeMeadowId` |

Каждая поляна имеет **фиксированный** rect/zoom своей Sunny Glade identity
(`WorldZones.gladeById`) — размер больше не «плывёт» с локальной семьёй.
Разблокировка следующей поляны по-прежнему от **размера семьи на активной**
полянe (пороги `minHerd`: 5 / 8 / 11).

### Стартовая семья новой поляны

При первом unlock поляна получает **1–2 Lv.1** (`BalanceV0.meadowStarterHerdSize = 2`),
чтобы сразу чувствовалась «новая опушка». Старая поляна хранит свою большую
семью без изменений.

### Миграция сейвов Act 1

Старый JSON без `meadows`:

1. Текущая семья → **первая** поляна (`warm_edge`).
2. Поляны `1…sunnyGladeAnnounced` помечаются открытыми; пустые получают
   starter herd при `init`.
3. `activeMeadowId = warm_edge`.

## UI

- Чип HUD **«Лес»** (🌲) → оверлей «Карта леса».
- Список/чипы четырёх полян: открытые кликабельны, закрытые с 🔒.
- Выбор поляны → `switchToMeadow` → загрузка её семьи; трава не сбрасывается.
- Крестик / повторный выбор активной → назад к игре.

Цели сессии остаются **глобальными** (следующий unlock / Lv.4).

---

## Self-check

- Нет soft-lock: всегда есть хотя бы `warm_edge`; переключение на
  открытую поляну всегда восстанавливает её семью.
- Трава никогда не уходит в минус (`_setState` clamp).
- Merge на одной поляне не отзывает unlock других.
- Offline / daily / grass spend — глобальные, без привязки к поляне.
