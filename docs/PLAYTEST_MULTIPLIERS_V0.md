# Playtest — Multipliers v0

Короткий чеклист для самопрогона до ревью Никиты.

## За 5–8 минут

1. **Еда:** тапай цветы → иногда 🌱/🫐/🥜; Уют → Еда → купить/покормить → полоска ускоряется.
2. **Места:** тап «Пень» / «Тёплый камень» или дроп капи → буст + CD; без спама.
3. **Роли:** long-press капи → Няня → авто растёт; второй слот недоступен до research.
4. **Дом:** купи Фонарик → авто +3%; проверь сейв/рестарт.
5. **Наука:** `more_flowers` → `longer_mud` / `more_berries` → путь к Тенту и 2-му слоту.
6. **Стек:** с Няней + Фонариком + Уют>0 авто выше базы; grass/uyut не уходят в минус.

## Как запустить

```bash
/home/box/flutter/bin/flutter run -d linux   # или chrome / android
/home/box/flutter/bin/flutter test test/multipliers_v0_test.dart
```

Открыть sheet: чип **«уют N»** или кнопка **«Уют · N🍽»** в spend-панели.
