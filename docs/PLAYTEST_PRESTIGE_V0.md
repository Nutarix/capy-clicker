# Playtest — Prestige v0 (Уют + Туманный бор)

Короткий self-check после shippable stub.

## Как попробовать

1. Дойти до **Большого луга** (семья 11+ на активной) и **Капи Lv.4** (merge).
2. Получить toast unlock / цель «Туманный бор» + **+1 Уют** (чип ✨ на HUD).
3. Открыть **Лес** → секция «Туманный бор» → войти на **Туманную опушку** (2× Lv.1).
4. Вернуться на старые поляны — семьи на месте, трава общая.
5. Авто-трава чуть быстрее (+3% за пункт Уюта).
