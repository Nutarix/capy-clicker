# Balance v0 — Capy Clicker (Phase 1–3)

Числа для короткой cozy-сессии + лёгкий offline. Источник правды в коде:
`lib/features/game/models/balance.dart` (`BalanceV0`).

## Авто-прогресс (трава)

| Параметр | Значение | Комментарий |
|---|---|---|
| `autoProgressPerSecond` | **0.015** (1.5%/с) | Полная шкала ~67 с без тапов |
| Тик | 50 мс | Сглаженный UI |

## Тап по цветку

| Параметр | Значение |
|---|---|
| `flowerTapGainMin` … `Max` | **+3% … +6%** за тап |
| Цветов на лугу | 5 (фикc. раскладка) |
| Juice | scale-punch + petal particles |

## Спавн капибары

| Параметр | Значение | Комментарий |
|---|---|---|
| `spawnThreshold` | **1.0** (100%) | |
| Overflow | переносится на следующий цикл | |
| `maxHerdSize` | **12** | soft-cap (Phase 2; был 10) |
| Старт | 1× Lv.1 | |
| Позиции | случайные, `minSpawnSeparation = 0.14` | |

При полном стаде прогресс клампится у порога (спавн не идёт).

## Merge

| Правило | Деталь |
|---|---|
| Условие | два капибары **одинакового** уровня |
| Результат | оба удаляются → один Lv+1 на позиции цели |
| Визуал | `baseCapySize=70`, `scalePerLevel=0.34` (ярче ступени Lv) |
| Визуальный потолок | **Lv.5–6** (крупнее + теплее amber tint + halo/badge) |
| Juice | золотой flash + scale punch ~520 мс |

## Камера (zoom)

| Стадо | Scale |
|---|---|
| 1–2 | **1.00** (близко) |
| 3–5 | **0.82** (середина) |

## Offline progress (Phase 2)

| Параметр | Значение | Комментарий |
|---|---|---|
| `offlineMinSeconds` | **8** | игнор коротких пауз |

| Формула | `autoProgressPerSecond × cappedSeconds` | без mud-буста |
| UI | snackbar «Пока тебя не было…» | один раз на запуск |
| Персист | `savedAtMs` в JSON сейва | |

|---|---|

Только визуал (CustomPaint), без новой механики.

## Грязевая лужа (mud wallow)

| Параметр | Значение |
|---|---|
| Позиция (норм.) | (0.22, 0.78), радиус хита **0.11** |
| Действие | перетащить капибару на лужу |
| Анимация | bounce + rotate + splash-частицы, **1.4 с** |
| Буст | **×2** к авто-прогрессу на **10 с** |
| UI | полоска золотеет, счётчик «грязь ×2 (Nс)» |

Повторный wallow обновляет таймер буста.

## Корзина ягод (berry basket)

| Параметр | Значение |
|---|---|
| Первый спавн | **8–16 с** после старта сессии |
| Респаун после сбора | **22–38 с** |
| Тап | **+18% … +25%** прогресса |
| Позиция (норм.) | (0.78, 0.72) |
| Визуал | спрайт корзины, лёгкий bob |

Редкий ресурс: не всегда на экране.

## Soft daily bonus — «Утренний уют» (Phase 2–3)

| Параметр | Значение | Комментарий |
|---|---|---|
| Частота | **1× / локальный календарный день** | не energy-gate, не FOMO-спам |
| Награда | **+25%** прогресса (`dailyBonusProgress = 0.25`) | эквивалент ~30 с грязевого буста задокументирован как альтернатива |
| Персист | `lastDailyClaimYmd` (`YYYY-MM-DD`) в сейве | |
| UI | bottom sheet «Утренний уют» + чип «Уют» пока не забрано | dismiss = «Позже», можно открыть снова |

## Первый запуск (tips)

| Параметр | Значение |
|---|---|
| Ключ | `capy_clicker_tips_seen_v1` |
| Tip 1 | «Перетащи капибар друг на друга» |
| Tip 2 | «Перетащи на лужу» |
| Dismiss | Пропуск / Понятно → больше не показывать |

## Персист

- `shared_preferences`, ключ `capy_clicker_game_state_v1`
- Сохраняется: `herdProgress`, `herd[]` (id/level/x/y), `nextId`, `savedAtMs`, `lastDailyClaimYmd`
- Debounce **400 мс**; буст/ягоды — сессионные (не пишутся)

## Feedback / audio (Phase 2–3)

| Платформа | Что |
|---|---|
| Mobile | `HapticFeedback.lightImpact` на тап цветка / wallow; `mediumImpact` на ягоды и merge |
| Web / desktop | без SFX (визуальный juice остаётся) |
| audioplayers | **отложен** — упаковка web+mobile без hassle; см. `store/README.md` |

## Вне скоупа v0

IAP, полноценный SFX/audioplayers, новые биомы.
