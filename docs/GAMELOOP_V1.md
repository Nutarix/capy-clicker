# Игровой цикл v1 — Grow! Capy!

Короткий cozy-loop на одну сессию. Не «бесконечный кликер», а явная цель → трава → выбор траты → слияние-навык → wow поляны → снова.

## Петля

1. **Цель сессии** (HUD «Цель: …»)
   - Ягодная поляна → Солнечный прогал → Большой луг → Капи Lv.4
   - Прогресс виден (семья к порогу поляны / max Lv к 4)
   - На завершении: мягкий toast + немного травы + следующая цель

2. **Трава (одно ресурсное «вилка»)**
   - Цветы: +прогресс **и** +1–2 🌿
   - Авто-тик: медленная 🌿
   - Корзина ягод: большой burst 🌿 (+прогресс как раньше)
   - Траты (панель):
     - **Позвать капи** (8 🌿) — спавн Lv.1, если семья < soft-cap
     - **Ускорение** (5 🌿) — короткое ×1.5 к авто (~6 с), слабее лужи
   - Лужа по-прежнему бесплатна (drag fun)

3. **Слияние как skill window**
   - Ручной drag + soft magnet (как было)
   - **Twin sparkle**: иногда пара одного уровня мягко подсвечена
   - Слияние именно этой пары даёт бонус 🌿 — поощряет внимательность, не auto-merge

4. **Ритм / wow**
   - Открытие поляны: toast «Открылась …» + SFX + 🌿 + лёгкая пауза juice
   - Цель сессии усиливает тот же beat

5. **Daily hook**
   - «Утренний уют» уже есть; в sheet добавлена строка «Сегодня: доберись до …» по текущей цели

## Персист

В сейве: `grass`, `sessionGoalIndex`, `twinIdA` / `twinIdB` (+ прежние поля).
