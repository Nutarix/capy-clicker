# 004 — План: имена и черты капи

Спека: [`spec.md`](spec.md). Шаги: [`tasks.md`](tasks.md).

## Коротко

- Имя и черта — поля `Capybara`. Выбор — чистая функция над «кто уже занят на земле», на своём `Random` от главы земли и id капи. Основной `core.random` и `lootRandom` не трогаются.
- Ядро: новая часть `GameNames` (`core/names.dart`) — имя при слиянии, тихая миграция при загрузке, переименование. Слияние зовёт её, правило «кто остаётся» — в `merge.dart`.
- Экран: имя на бейдже при касании, черты в блуждании (`CapyTraitWander`, только виджет), позы сони и мечтателя из нового арта, «Роли» с именами и переименованием, имя в главе ракеты.
- Новых зависимостей нет.

## Т1, Т4. Модель

`models/capy_names.dart`:

- `CapyTrait` — шесть черт: `sleepyhead`, `fidget`, `sweetTooth`, `splasher`, `cuddler`, `dreamer`. У каждой `id` для сейва, RU/EN название и форма прозвища (`Шишка-соня` / `Sleepy Pinecone`).
- `CapyName` — ключ (английское имя строчными: `button`, `pinecone`…), RU, EN. `CapyNames.all` — сто имён в порядке `NAMES.md`. Ключ не зависит от порядка списка.

`Capybara` получает `nameKey`, `nameEpithet` (имя с чертой), `customName`, `trait`. JSON: `name`, `epithet` (только `true`), `customName`, `trait` — в конце объекта и только если заданы. Старый сейв без полей читается как безымянный. `copyWith` переносит поля, `==` их учитывает.

Показ: `customName` как есть, иначе RU-имя, с чертой — `Шишка-соня`. Безымянный в списке — «Малыш».

## Т2, Т3. Выдача

`models/capy_naming.dart`, `CapyNaming.assign(capy, used:, landChapter:)`:

1. Свой `Random(seed)`, `seed` — из главы земли и id капи (стабильно, без `hashCode`).
2. Черта: `nextInt(6)`.
3. Имя: свободные из ста (ключ не занят ни одним капи земли) — случайное из них.
4. Все сто заняты: имя с чертой капи, пара (имя, черта) не занята.
5. Занято и это — другая черта с свободной парой; совсем нет — повтор (600 на землю не набрать).

«Занято» — все поляны земли (`withActiveSynced().meadows`), архивные земли — каждая отдельно. Своё имя игрока ключ не освобождает.

`GameNames` (`core/names.dart`):

- `nameMerged(...)` — для слияния.
- `migrate(state)` — при загрузке: каждая поляна текущей земли, потом каждая архивная земля (её `meadows` и `herd`, один капи — одно имя). Только уровень ≥ 2 без имени. Без сообщений.
- `rename(id, text)` — обрезка пробелов, до 16 символов, пустое — `false`. Только у названных капи. Любая поляна земли.

`core.random` в выборе не участвует → случайные числа игры прежние (Т3).

## Переходное правило слияния

`GameMerge.tryMerge`: цель с именем → имя/черта/своё имя цели; иначе перетаскиваемый с именем → его; иначе (двое безымянных) → новое имя и черта, сообщение `CapyNamed` «Малыш подрос — теперь это <имя>». Занятые имена считаются без этих двоих.

Сообщение — слот в `GameMessages`, после роли в `flush`. Экран показывает плашку.

## Т5. Тексты без рода

«Малыш подрос — теперь это …», «Летит …», «… в пути». Тест ищет родовые слова в новых строках.

## Т6. Имя на лугу

Луг держит `_nameShown` (id) и таймеры. Касание капи (`Listener`, `onPointerDown`) — имя видно; отпускание — скрыть через 2 с. Цель магнита и `DragTarget`-кандидат показывают своё имя, пока над ними тащат. Картинка под пальцем — с именем. Бейдж: `Пуговка · Lv.2`; ширина бейджа не двигает спрайт (`OverflowBox`). Малыш — только уровень.

## Т7. «Роли»

Под карточками ролей — «Семья на поляне»: строки `Пуговка — няня` / `Lv.2 · соня`, малыши — «Малыш». Карточка роли — с именем того, кто её держит. Нажатие на имя → поле (16 символов, обрезка, пустое не принимается), сохранение сразу (`GameController.renameCapy`). Капи из долгого нажатия — сверху и подсвечен. Лист поднимается над клавиатурой. Селектор вкладки — строка-подпись строк (значение, не тождество списков): ход шкалы не перестраивает.

## Т8. Черты в блуждании

`models/capy_trait_wander.dart`, чистые функции, только для виджета. Ядро (`_pickSpawnPosition`, стартовые семьи) их не зовёт.

| Черта | Что |
|---|---|
| непоседа | две пробы цели, берётся дальняя; ходьба ×0,75 по времени, паузы ×0,6 |
| лакомка | корзина видна → с вероятностью 0,7 цель у корзины (дуга ~0,13 от центра) |
| плюх | лужа есть → с вероятностью 0,65 цель на краю: дальше `mudHitRadius` + запас, тело не на кольце лужи |
| обнимашка | приятель — стабильно по id среди семьи; цель рядом с ним, на ширине тела плюс полоска травы |

Цель черты проверяется теми же правилами (`hitsProp`, `overlapsPeer`, на траве) и режется `clipTravel`. Не подошла — обычная цель. Цифры игры не меняются: позиции — та же `updatePosition`, что и у обычного блуждания.

## Т9. Соня и мечтатель

Арт: `tool/slice_traits_pack.py` (ниже). В виджете — поза вместо прогулки: соня с вероятностью 0,35 дремлет 7–11 с (дыхание 2 кадра, пузырёк растёт 0→1→2 и лопается), мечтатель с вероятностью 0,3 смотрит вверх 4–7 с (глаза открыты, иногда полуприкрыты). Перетаскивание, слияние, валяние обрывают позу сразу (как прогулку). Поза рисуется в масштабе походки, ноги на той же линии.

## Т10. Ракета

`GameLands.nextTraveler` — тот же выбор «кто летит», вынесенный из `launchToNewLand`. Если у него имя: «Летит Пуговка. Остальные остаются дома.», «Пуговка в пути».

## Итоги

- Т1–Т13 сделаны. `flutter analyze` — без замечаний, `flutter test` — 271 зелёных дважды (до спеки 216).
- Т13: отпечаток перезаписан один раз, после модели. `python tool/fingerprint_names_diff.py main`: во всех семи файлах после вырезания `name`/`epithet`/`customName`/`trait` у капи (и в блобах сейва внутри `save_store`/`session`) текст побайтно равен `main`, данные тоже; вырезано 899 групп полей. `live_tick` не изменился. Проверка скрипта: правка одной цифры травы в `session.jsonl` — «DIFFERS».
- Т12: `names_balance_test` — одна длинная сессия (рост, слияния, тапы, корзина, лужа, поляны, туман, ракета, визит назад, сейв и загрузка) с именами и без (`debugNames: false`): все пробы без полей имён равны. Если выбор имени возьмёт хоть одно число из `core.random` — тест падает (проверено).
- Арт: `tool/slice_traits_pack.py` → `assets/images/traits/` (10 + 10 поз 320×288, 3 пузырька 128×128). Фигуры режутся по пустым столбцам (сон шире четверти листа), бежевая тень под лапами снимается, сторож отражён покадрово, масштаб — походки своей внешности. Превью: `store/art-pack-traits/preview-processed.png`. Нос для пузырька задан руками (`CapyPose.sleepNose`).
- Сборка веба собрана и проверена в браузере: соня спит с пузырьком, мечтатель сидит и смотрит вверх, чип «Пуговка · Lv.2» у касания, «Роли» с именами, переименование.

Отступления и решения:

- Переименовать можно только названного капи; малыш в списке — «Малыш», без поля.
- Слитый капи показывает имя ещё 2 с после слияния (видно, кто остался).
- «Роли»: капи из долгого нажатия — сверху, потом карточки ролей, потом семья поляны (только активная поляна; держатель роли с другой поляны виден в карточке «Сейчас: …»).
- Своё имя игрока не освобождает игровое имя-ключ (на земле оно остаётся занятым).
- Тап по спящему (без сдвига) может разбудить: арена жестов на отпускании отдаёт победу перетаскиванию с нулевым сдвигом, как и до спеки. Сон обрывается тем же путём, что и прогулка.
- «Один улетает», «Один в пути» (мужской род) — прежний текст для безымянного малыша, не трогали: вне рамок Т5, которое про новые тексты.

## Риски

- Черты видны не сразу: цели черт — с вероятностью 0,65–0,75 на ход, позы — 0,35/0,3 на ход. Если Никите мало — поднять числа в `CapyTraitWander`/`CapyPose`.
- Лакомка на маленьких полянах: корзина у края, свободной точки рядом может не найтись — тогда обычная прогулка.
- Чип имени шире капи может накрыть соседа на тесной поляне (2 с).
